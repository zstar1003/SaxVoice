# SaxVoice 曲谱库扩展

目标：静态 GitHub Pages 曲库，可搜索中文、英文和拼音，切换曲目与降 B 高音、降 E 中音、降 B 次中音。每个版本提供实际 A4 PDF、谱页预览和 MusicXML。

保留已经认可的《诀别书》高音文件；从同一结构谱生成中音和次中音。新增七首传统／经典旋律，从公开历史旋律重新录入，单声部独立排版，说明主题版与传统旋律版范围。

实现：结构化旋律输入 → 乐器移调与音区检查 → MusicXML → Verovio 矢量 A4 PDF → 预览图片与统一 catalog.json。前端使用数据驱动曲目列表、搜索、类型筛选、乐器切换、分页、下载、打印和可分享 URL。

验证：所有小节时值与延音线、乐器移调与音域、PDF A4 尺寸与矢量内容；浏览器验证搜索、切换、空结果、深链接、键盘、移动端与打印页数。推送 main 并确认 GitHub Pages 部署。
