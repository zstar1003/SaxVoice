# SaxVoice 网站设计

## 目标与确认的范围

为《诀别书》整理萨克斯曲谱来源，创建公开开源网站，通过用户指定的 GitHub Pages 部署。用户确认目前没有转载授权，先发布谱源链接。

## 实现选择

采用零依赖静态 HTML/CSS/JavaScript。单页足以完成找谱、查看原始来源与了解选谱注意事项；无需服务器或数据库。相较框架方案，静态网站减少维护与构建成本；相较复制完整谱文件，链接发布符合本次用户确认的内容范围。

## 视觉与交互

深绿黑色底、黄铜色强调，衬线曲名与浅色曲目封面形成音乐书架风格。封面只展示曲名与元信息，不冒充曲谱预览。桌面双栏、移动端单栏。首屏直达谱源列表。三个谱源卡片打开无网络请求的详情弹窗，展示当前发布者、获取方式、授权状态与核验日期，然后链接至原始发布。弹窗支持 Esc、关闭按钮、焦点管理与键盘操作。禁用 JavaScript 时保留直接来源链接。

## 发布与验证

MIT 许可仅覆盖原创网站代码。独立文档记录来源核验与授权边界。GitHub Actions 在 main 推送后将 site 目录发布到 GitHub Pages。交付前检查桌面与手机布局、每个谱源链接、弹窗键盘交互、浏览器控制台及实际 Pages 部署结果。
