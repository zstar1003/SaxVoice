# SaxVoice 简洁阅读器

按用户指定，以 Apple Developer 文档为参考：白与浅灰底色、系统字体、蓝色操作、细分隔线、克制的半透明浮动控件。没有营销首屏或装饰性编号。

桌面左侧可搜索曲目目录，右侧直接展示曲谱。标题附近仅保留作者、乐器切换及下载入口。页码、缩放、打印、分享集中在一个阅读工具条；详细版本、来源及移调信息收进默认折叠的“曲谱信息”。移动端目录抽屉可随时打开，并提供搜索、分类、当前选中项和关闭操作。

保留已认可的谱文件与既有分享链接。扩充到约 20 首曲目，各具高音、中音、次中音实际 A4 PDF 与 MusicXML。新增历史旋律经逐小节录入、时值与移调检查，并视觉核对排版；制谱器支持长曲多页和按需生成，避免无关重建改变原文件。

验证：新曲三种移调、音域、时值及延音线，所有 A4 页面；桌面／手机截图、搜索、键盘、分页、目录抽屉、全屏阅读、下载与打印。推送后确认 GitHub Pages 和线上资源。
